# 专题作品4：漫步的考古史

> 漫步是我的探铲。每走错一步，都敲到一层更深的土。

一本个人考古小册子。不是人生回顾，而是把那些年走过的路一块块挖出来——不是为了证明我终于找到了正确人生，而是想看见：一个总是在外部平台、外部声音和外部机会中寻找自己的人，究竟是怎样慢慢学会，给自己造一块土的。
